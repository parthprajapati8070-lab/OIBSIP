# Weather App

A Python-based Weather App developed as part of the Oasis Infobyte Internship Program.

## Features

- Fetches real-time weather data using OpenWeather API
- Displays temperature, humidity, feels-like temperature
- Shows weather condition and wind speed
- Converts wind speed to km/h
- Categorizes weather as Cold, Pleasant, Warm, or Hot
- Provides weather-based advice
- Handles invalid city input
- Shows timestamp of weather check

## Technologies Used

- Python
- Requests Library
- OpenWeather API

## How to Run

1. Install requests:
   pip install requests

2. Run the program:
   python weather_app.py

3. Enter a city name.
